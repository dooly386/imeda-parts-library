# NOTICE

This repository is a **format conversion** of the Celestial Altium Library
(https://github.com/issus/altium-library.git, commit 8b4124061296e84a8680b0974abc0290555b1383) by Mark Harris and contributors.
Schematic symbols and PCB footprints were converted from `.SchLib` / `.PcbLib` to the
ImEDA canonical text format (s-expressions). No symbol or footprint was authored here;
credit for the library work belongs to the original authors.

Source website: https://altiumlibrary.com
