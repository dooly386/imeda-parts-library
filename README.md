# imeda-parts-library

Schematic symbols and PCB footprints for [ImEDA](https://imeda.net), converted from the
[Celestial Altium Library](https://github.com/issus/altium-library) (see NOTICE.md for attribution and license).

| | count |
|---|---|
| symbol libraries | 110 |
| symbols | 7865 |
| footprint libraries | 95 |
| footprints | 2201 |
| component records | 7492 |

Source commit: `8b4124061296e84a8680b0974abc0290555b1383` · converted 2026-09-21.

## Layout

- `symbols/<Category>.imslib.src/symbols/*.imsym` — one symbol per file (ImEDA canonical text, plan 214-02)
- `footprints/<Group>.imflib.src/footprints/*.imfp` — one footprint per file
- `components/<manufacturer>/<mpn>.json` — one part record per file (plan 243-03 schema); `symbolRef.path` points at the symbol file
- `manifest.json` — conversion record: source commit, counts, files that failed, symbols without a part record and why

## Using it in ImEDA

Register this repository URL as a library source (plan 243-03-02). ImEDA clones it, imports the text into
local `.imslib` / `.imflib` files and indexes `components/` for part search. The SQLite library files are
build products and are not stored here.

## Not included

- 3D models (STEP) — separate repository, pending.
- Part parameters, pricing, datasheets and symbol↔footprint links — those live in the source project's
  hosted database and are not part of the GitHub files. Records here carry only what the file names state:
  manufacturer, MPN, category.

Regenerated by `scripts/parts_library_build.mjs` in the ImEDA repository; edits made by hand here are overwritten on the next run.
